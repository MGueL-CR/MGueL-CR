### 📁 Proyectos Destacados

Aquí puedes ver el ecosistema de código abierto que mantengo activamente, además de otras herramientas:

#### 🐧 Ecosistema GNOME (Linux)
*   **[re-notification-center](https://github.com)**  
    🚀 **Mantenedor Principal** | Una extensión avanzada para **GNOME Shell** que permite desacoplar y personalizar por completo el centro de notificaciones de Linux. Es un *fork* activo adaptado para mantener compatibilidad total con versiones recientes (GNOME 40 hasta GNOME 50).
    
*   **[re-notification-center-documentation](https://github.com-documentation)**  
    📖 **Espacio de Documentación** | Repositorio dedicado a desglosar, organizar y explicar a fondo la arquitectura técnica interna de la extensión para facilitar la llegada de nuevos colaboradores.
    
    🌐 **Sitio Web oficial del proyecto:**  
    [![Deployed with Vercel](https://shields.io)](https://vercel.app) *(¡Visita la documentación en vivo!)*

#### 🛠️ Herramientas y Fundamentos
*   **[Fix_Update_KB5034441](https://github.com)**  
    💻 Un script semiautomático en **PowerShell** diseñado para solucionar problemas complejos de instalación con la actualización KB5034441 en Windows 10 y Windows 11.
    
*   **[Oracle_Java_Foundations](https://github.com)**
