### 📁 Proyectos Destacados

Aquí puedes ver el ecosistema de código abierto que mantengo activamente, además de otras herramientas:

#### 🐧 Ecosistema GNOME (Linux)

- **[Location-Quick-Toggle](https://github.com/MGueL-CR/Location-Quick-Toggle)**  
    📍 Una extensión útil y nativa para **GNOME Shell** que añade un interruptor rápido al panel de *Quick Settings* de Linux para activar o desactivar los servicios de ubicación global de forma inmediata. Desarrollada en JavaScript bajo la arquitectura ES Modules, ofrece compatibilidad fluida desde GNOME 45 hasta GNOME 49.


- **[re-notification-center](https://github.com/MGueL-CR/re-notification-center)**
  🚀 **Mantenedor Principal** | Una extensión avanzada para **GNOME Shell** que permite desacoplar y personalizar por completo el centro de notificaciones de Linux. Es un _fork_ activo adaptado para mantener compatibilidad total con versiones recientes (GNOME 40 hasta GNOME 50).
  
- **[re-notification-center-documentation](https://github.com/MGueL-CR/re-notification-center-documentation)**  
  📖 **Espacio de Documentación** | Repositorio dedicado a desglosar, organizar y explicar a fondo la arquitectura técnica interna de la extensión para facilitar la llegada de nuevos colaboradores.
